# 📘 Assignment: Data Cleaning and Visualization with Python

## 🎯 Objective

Clean a messy dataset in Python and create simple visualizations to help explain the results. This assignment focuses on real-world data preparation, basic analysis, and clear communication of findings.

## 📝 Tasks

### 🛠️ Load and Clean the Dataset

#### Description
Begin by reading the provided CSV file and fixing common data issues so the information is usable for analysis. The goal is to turn inconsistent raw data into a clean table.

#### Requirements
Completed program should:

- Read the CSV file using pandas
- Identify missing, blank, or inconsistent values
- Standardize repeated values such as text case or spacing
- Convert columns to the correct data types when needed
- Remove or fill invalid entries in a sensible way
- Print a cleaned summary of the dataset

### 🛠️ Explore the Data

#### Description
Once the data is clean, examine the results to answer a few simple questions about the dataset. This task helps students understand how to summarize information before visualizing it.

#### Requirements
Completed program should:

- Calculate basic statistics such as averages or counts
- Filter rows based on a condition or category
- Summarize important trends in the data
- Explain what the results mean in plain language
- Use clear variable names and readable output

### 🛠️ Create Visualizations

#### Description
Turn your cleaned data into simple charts that make the patterns easier to understand. The visualizations should support the insights you found during analysis.

#### Requirements
Completed program should:

- Create at least one bar chart or line chart
- Label the axes clearly
- Use a meaningful title for each visualization
- Show the relationship between variables in a readable format
- Save or display the chart in the output
