# 📘 Assignment: Games in Python

## 🎯 Objective

Create a simple Python game that uses user input, loops, and conditionals to make an interactive experience for players. This assignment helps you practice working with strings, randomness, and game-state logic.

## 📝 Tasks

### 🛠️ Build the Game Setup

#### Description
Create a simple word-based game where the player tries to guess a hidden word one letter at a time. The game should react to correct and incorrect guesses and keep track of the current state.

#### Requirements
Completed program should:

- Choose a random word from a list of predefined words
- Show the hidden word as underscores or blanks for unguessed letters
- Accept single-letter guesses from the user
- Reveal matching letters in the correct positions
- Track how many wrong guesses remain
- End the game when the player wins or runs out of chances
- Display a clear win or loss message at the end

### 🛠️ Improve the Gameplay Experience

#### Description
Add a few quality-of-life features to make the game more polished and user-friendly. These improvements should make the game easier to play and more rewarding to finish.

#### Requirements
Completed program should:

- Prevent repeated guesses from counting multiple times
- Display the letters already guessed by the player
- Tell the player whether their guess is correct or incorrect
- Keep the game loop running until the player chooses to quit or the round ends
- Use clear prompts and readable output formatting
